# EBRIONAUTAS 👽🍷🎲

*Encuentros en la Tercera Copa.*

Juego de mesa virtual multijugador de extraterrestres borrachos, basado en el
tablero "El Nuevo Ocalimocho". Una pantalla grande muestra el tablero y cada
jugador se conecta desde su celular (QR/URL) para tirar el dado y gestionar su
Ficha de Ebrionauta.

Plan completo: [docs/plan-ebrionautas.md](docs/plan-ebrionautas.md)

> Juego para mayores de 18 años. Bebe con moderación.
